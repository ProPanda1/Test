# Squad Rush: Last Stand

A portrait mobile browser shooter inspired by classic upgrade-gate game ads.

## Play

- Live immutable build: https://raw.githack.com/ProPanda1/Test/f8e3c50149bdaa03630db7934f2ae98066a0a2ee/index.html
- Latest master build: https://raw.githack.com/ProPanda1/Test/master/index.html

## Controls

Drag left and right to steer. Shooting is automatic. Choose upgrade gates before waves and one of three upgrades after each cleared wave. Use Heal when damaged and Airstrike at 100% charge.

The campaign contains 12 waves and bosses on waves 4, 8, and 12. The entire game is self-contained and uses no external assets or backend services.
